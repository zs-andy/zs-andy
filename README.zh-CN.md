<summary>数据与统计方法</summary>

统计包含归属于 **zs-andy** 提交的公开及获授权私有仓库（基于 GitHub 贡献记录与可访问分支校验，排除第三方复制仓库）。各仓库先按 GitHub Linguist 计算语言占比，再等权取平均，反映仓库语言结构而非个人代码行数。仅公开汇总数据与仓库总数，不泄露具体仓库或提交信息。
